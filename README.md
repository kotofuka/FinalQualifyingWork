# PhotoMakeupApp
На данноей ветке будет разрабатываться приложение для разметки фотографий анкет. Оно позволит вручную выделять 
прямоугольники по 2-м точкам на фотографии. А в последствии создает "JSON" объект с координатами этих обектов на фото.

Это программа служит, для подготовки фотографий к бинаризации отдельных ее частей.

Для создания приложения используется язык программирования Java и фреймворк JavaFX.
